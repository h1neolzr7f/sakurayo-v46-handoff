# 浏览器冒烟测试清单

## 启动
- 清空存档后打开主菜单。
- 使用旧字段不完整的 `sakurayoV3` 存档打开主菜单。
- 角色卡、商店、关卡和开始按钮均可点击。

## 三角色
- 小夜：第七发贯穿压制弹。
- 绫：第四次手枪攻击触发居合。
- 凛音：纯近战可以主动接敌，第三刀触发剑势和恢复。

## 成长
- 至少触发两次升级。
- 职业成型、9级转职、12级和15级升阶可用。
- 双职业满足条件时融合选项出现。
- 三相飞升条件满足后可选择。
- 升级池为空时仍有兜底选项。

## UI
- 剧情出现时吐槽和系统提示收起。
- 返回战斗后队列恢复。
- Boss 警告不覆盖技能按钮和剧情文本。
- 430×932、360×800 和横屏各测试一次。

## Boss
- 75%、50%、25% 阶段依次触发。
- 高爆发不能跳过阶段。
- 阶段召唤物有数量上限。
- Boss 死亡后正常进入结算。

## 结算与重开
- 伤害与构筑报告正常。
- 奖励和成就写入存档。
- 返回菜单后可以再次开局。
