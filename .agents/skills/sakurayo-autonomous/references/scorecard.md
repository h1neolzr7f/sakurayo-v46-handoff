# 木桶评分（1–10）

先根据当前代码、截图和测试打分，再改最低项。10 = 发给二游玩家也不会像网页 Demo。

| 项 | 看什么 | 低分信号 |
| --- | --- | --- |
| 玩法 | 职业/融合/飞升/三种模式还在且能玩 | 选项空洞、模式串台、升级后卡死 |
| 稳定性 | 不崩、旧档能进、测试绿 | 红测、ReferenceError、清档 |
| 架构 | 核心函数还在，无包装层 `update` | 调用点丢失、无界碰撞 |
| UI | 五房同一套玻璃，信息不叠 | 程序员按钮墙、模态+吐槽同时挡 |
| UX | 大厅→出击→结算→回大厅 | 找不到出击、竖屏当主体验 |
| 角色表现 | 三角色像同一个人 | 大厅/卡面/头像三张脸 |
| 场景美术 | 大厅宽背景、战场可读 | `lobby_wide` 黑边、立绘裁头 |
| 动画 | 站桩/技能/dash 对得上角色 | 借错融合图、静止贴纸 |
| VFX | 打击、转阶段、部署有反馈 | 只有数字没有演出 |
| 剧情演出 | 抉择改变关系/Boss/结局 | 纯文本弹窗 |
| 音频 | 有反馈且不刺耳 | 完全无声或循环爆炸 |
| 移动端性能 | 430×932 中端机能撑 | 粒子爆炸、对象无上限 |
| 完成度 | 能发版的闭环 | 半成品房间、缺验收 |
