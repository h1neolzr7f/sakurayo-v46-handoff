# 视频立绘包（绿幕 / 透明）

给宣传片、剪辑和 I2V 用。游戏运行时仍读 `android-app/.../game/art`，这包不进局内。

尺寸一律 **1024×1536（3:4）**，无字、无水印。

## 怎么用

| 目录 | 用途 | 色键 |
|---|---|---|
| `chroma/` | 剪辑抠像、I2V 站桩 | 主角 `#00FF00`；僵尸 `#FF7A00` |
| `alpha/` | AE / CapCut / Premiere 直接叠层 | 透明 PNG |
| `contact_sheet.jpg` | 九宫格预览 | — |

主角不要用橙幕（衣服/枪没有绿色）。僵尸不要用绿幕（眼睛和符纸容易发黄绿，统一橙幕 `#FF7A00`）。

## 剪辑建议

1. 先用 `alpha/` 做标题卡、过肩镜头、角色介绍。
2. 要做 I2V 站桩动画，用 `chroma/` 里的三角色，绿幕 `#00FF00`。
3. 正式 UI 字由后期加，不要让生图带中文。
