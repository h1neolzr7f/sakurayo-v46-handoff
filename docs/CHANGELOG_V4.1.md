# 《樱夜·尸潮 V4.1：扩展框架》更新记录

## V4.1.2 · 镜路探索

- 启动资源分级：首屏只预载三名角色头像与六枚主导航图标；敌人、Boss 阶段图和战斗动作图改为遇到时按需解码，避免冷启动把 28 张战斗图一起压进 WebView。
- 四张探索地图增加可行走区域与 16px 物理碰撞；移动采用分轴滑动，碰到道路边界时可以沿墙移动，不会被背景装饰误导为可通行区域。
- 每章新增一件由剧情事件解锁的隐藏奖励，并提供有前置线索、两种后果和独立持久化的地图事件；局部扩展存档从版本 1 声明式迁移到版本 2。
- 11 类普通/特殊敌人增加代码绘制的高对比轮廓部件，迅捷、重甲、远程、自爆、结界、干扰、净化、幽魂、腐败、封灵与精英不再只靠颜色区分。
- 四章 Boss 复用已有 16 张 Image2 阶段立绘，增加跨阶段交叉淡入、缩放旋转冲击与章节独立场景边缘效果；低画质自动关闭额外场景层。
- 未修改刷怪、伤害、职业、融合、主神空间和 Boss 数值；按要求不处理吐槽框布局和真人平衡样本。
- 框架专项 6/6、完整浏览器流程 40/40 通过；Android 更新为 versionCode 43 / versionName 4.1.2。

## V4.1.1 · 醒目角色

- 冷启动改为无需图片即可首帧显示的 CSS 加载层，等 `window.load` 后再退场；资源解码较慢时不再提前露出黑屏。
- Android 12+ 新增深色原生启动主题，移除白底闪屏，并继续复用本地应用图标而不增加大图加载成本。
- 探索地图角色显示由 84px 调整为 118px，增加角色专属识别色、白色外描边、定位光环和姓名短标。
- 探索角色会随左右移动翻转，移动时显示轻量拖影；背景仅在人物附近形成柔和聚焦光，不遮挡地图细节。
- 战斗角色增加白色＋专属色双层脚底定位环，怪海中仍能快速锁定主角。
- 视觉尺寸与物理判定彻底分离：探索和战斗的玩家碰撞半径继续保持 16px。
- 扩展专项 6/6、完整浏览器流程 39/39 通过；Android 更新为 versionCode 42 / versionName 4.1.1。
- 新增 `official.feedback` 官方反馈包：精选 Kenney CC0 界面音效与粒子纹理，接入菜单按钮、奖励拾取、Boss/转阶段提示和枪口闪光。
- 免费素材保留本地许可证与来源清单；反馈包缺失或解码失败时继续使用本体程序化音效/Canvas 特效。

## 架构

- 从 V4.0.0 基线增加内容包注册、独立存档、声明式迁移、受保护事件和故障隔离。
- 开发态拆出运行时、清单和内容包；发布与 Android 仍生成无外部脚本的离线单入口。
- `android-app/sync-game.ps1` 改为调用确定性构建器并执行静态门禁，不再直接复制单体 HTML。
- `sakurayoV3` 保持不变；旧档自动补 `extensions`，坏包不会清空本体存档。

## 官方示例扩展

- 新增薄樱观测服，三角色共 21 个离线服饰资源。
- 新增收藏道具“扩展观测手册”、成就“框架观测员”和扩展档案。
- 新增故意损坏扩展夹具，用于验证错误记录和启动隔离。

## Image2 剧情探索

- Image2 新制四张剧情地图：神社外街、雨夜商圈、黄泉剑冢、镜界核心。
- 每章关卡卡新增“探索地图”，支持触屏摇杆与 WASD、跟随镜头和自动拾取。
- 每图包含三处一次性奖励，收集记录保存在探索包自己的存档段。
- 地图加载失败时使用程序化背景，仍可移动、拾取和退出。

## 保持不变

- 不改 V4.0 的刷怪、伤害、职业、24 种融合、Boss 和主神空间数值。
- 正式模式仍不暴露 `__SAKURAYO_TEST__` / `__SAKURAYO_BETA__`；测试参数行为保留。
- 全部资源离线，无 CDN、远程字体和远程图片。
