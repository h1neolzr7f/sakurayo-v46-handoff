> 目标：**好玩，并且和玩法严丝合缝**：肉鸽循环、死亡、形态、多玩法、构筑、樱花币、故事卡都要在故事里自然成立。

## 0. 一句话

> 说书人（狸老板）：「诸位看官——你可听说过，**大食切**的故事？」

**二百年前，黑羽流剑士千代与铁炮手朔夜，在百夜祭上斩落了吞噬夜晚的大食般若。朔夜为护千代而死；千代悲愤之下拔出奥义「千夜一闪」，把般若连同半座樱夜山一齐斩开。斩何物，便名何刀——可惜记录此战的瓦版记者神代氏写道：般若死时嘴里还塞着三十串章鱼烧。于是这把刀，就被叫作了「大食切」。**

**二百年后，夏祭最后一夜，烟花倒带，时间回到 18:00。黑羽凛音背着那把名字很丢人的刀，月城小夜和神代绫戴着狐面，被卷进了一个停不下来的夜晚。**

- 风格：**一本正经的古风史诗腔调，讲荒诞的事**（参考 AI 短剧《大只切》的「生草与感人平衡」，见 §9 来源）。说书人旁白用古风字体与说书腔；角色对话保持现代吐槽。
- 核心谜团：**这一次吃掉夜晚的般若，是谁？**（答案：二百年前死去的朔夜——她化成了鬼，月城小夜的先祖。）
- 结构：**百夜祭循环（玩法框架）× 刀名传说（情感主线）× 代际传承（三人的先祖）**。

## 0.5 二百年前的三个人（传说篇，以说书 + 故事卡呈现）
| 当年 | 身份 | 今天的后人 | 传承 |
|---|---|---|---|
| **黑羽千代** | 居合剑士，话少，爱睡 | 黑羽凛音 | 刀「大食切」与奥义「千夜一闪」 |
| **月城朔夜** | 铁炮手，千代亦师亦友的姐姐，穷，乐天 | 月城小夜 | 樱花纹的铁炮 → 小夜的步枪；那句口癖「没问题没问题」 |
| **神代某（瓦版记者）** | 记录了这场战斗，并给刀起了丢人的名字 | 神代绫 | 「把看到的都写下来」——今天她开直播 |

- 朔夜为护千代被般若踩在脚下，临死前说：「千代，刀要快——快到它来不及跑。」千代化悲愤为力量，骑上般若的脖子，一刀一刀燃尽刀身，最后一斩连同半座樱夜山一起斩开（今天的「切山」）。
- 千代把般若的獠牙嵌进刀镡，刀从此叫「大食切」。千代一生没再笑过——直到故事卡「千代与朔夜的童年」里，我们才知道她们小时候也一起逛过百夜祭。

## 1. 世界观 ↔ 玩法（全部在故事里成立）

| 玩法 / 系统 | 故事里的样子 |
|---|---|
| 肉鸽一局 | 一夜。18:00 鸟居下出发，沿着祭典地图逛摊位，23:59 前要走到本殿。 |
| 死亡 | 「出局」。眼前一黑，回到 18:00 的鸟居下，面具屋的**狸老板**递来一串苹果糖：「第几次了？」——死亡就是回家，不是 Game Over。 |
| 四层地图 | 祭典四个区：①参道 ②夜店街 ③河边花火会场 ④本殿。层主是各区的「摊主大将」。 |
| 多玩法切换 | 祭典摊位就是玩法：**鬼退治**（割草主玩法）、**射的屋**（纵版射击）、**弹珠屋**（弹珠）、**奉纳相扑**（格斗）。宵规定「过关就要玩她的摊」。 |
| 构筑卡 | **御神签**。局内抽签：大吉 = 稀有卡；「凶」签也能用，只是效果奇怪。 |
| 遗物 | **祭典奖品**：金鱼、水气球、面具挂件，一夜有效，天亮（循环）就消失。 |
| 魂晶（局内币） | **夜店券**，只在今夜的摊位通用。 |
| 樱花币（局外） | **奉纳钱**。宵承认的「神的货币」，是唯一不会被倒带抹掉的钱——所以小夜疯狂攒。 |
| 形态 | **面具 · 变身**（像特摄的变身：喊出口号、戴上面具）。狸老板卖的狐面、天狗面、般若面等对应 守 / 速 / 爆；**觉醒 = 每个人小时候自己画的那张纸面具**（Boss 第 4 阶段才戴得上）。 |
| 外观（华彩 / 传说） | 同一张面具的高级漆版，只改外观。 |

| 循环为什么存在 | 般若会吃掉夜晚；祭神宵每次在它吃到天亮前把夜晚倒回 18:00——循环是宵的封印，也是她的极限。 | |
| 深渊夜（难度） | 宵心情不好时的「加班夜祭」：摊位规则变刁钻。 |
| 每日挑战 | 宵每天换一张「今日特别摊」告示。 |

## 2. 三位主角（人设与武器不变）

### 月城小夜 · 步枪 · 「穷，但永远有干劲」
- 樱夜荘最穷的租客。**小目标**：赢下祭典大奖「奉纳钱 100 万」交房租。对循环的第一反应：「每天都能重新抽签？那不就能无限刷奖品吗！」
- 口癖：「没问题没问题！」「这个能换多少奉纳钱？」
- 化学反应：冲在最前面的引擎；对绫的吐槽免疫；总给凛音带吃的。
- 面具台词：狐面（守）「挨打要花药钱的，所以不挨！」/ 天狗面（速）「下一个摊位 5 分钟后收摊——让开让开！」/ 般若面（爆）「房租的仇，今天一起报！」/ 觉醒·纸面具「……这张脸，是我七岁时画的。」

### 神代绫 · 双枪＋太刀 · 「主播，毒舌，最清醒」
- 镜界探险主播转「祭典探店主播」。**小目标**：涨粉。循环的悲剧：每次倒带，**粉丝数也倒带**。
- 口癖：「证据呢？」「这段我剪进去了。」
- 化学反应：唯一一个认真调查循环规律的人（会做笔记，笔记也会被倒带，所以写在手臂上）；和小夜是「傻瓜和吐槽」；对凛音有种说不出的怀疑。
- 面具台词：狐面「全程录屏，你每一拳我都截图了。」/ 天狗面「下面这段请开 0.25 倍速。」/ 般若面「掉粉的怨念，接好！」/ 觉醒「……原来那次直播，第一个观众是你们。」

### 黑羽凛音 · 太刀 · 「想睡觉的最强」
- 居合传人，人生目标是「睡十二个小时」。**对循环的态度：赞成。**「今夜不结束，明天就不用上学。」——前两层是半个「内鬼」，会偷偷在摊位上拖后腿（玩家能发现的伏笔）。
- 口癖：「……嗯。」「好麻烦。」
- 化学反应：话最少、出刀最快；总能提前说出接下来会发生什么（「左边。」——下一秒左边就冒出祭灵）。
- 面具台词：狐面「我就站这里。你们过来。」/ 天狗面「三分钟后睡觉。一刀一个。」/ 般若面「……谁把我吵醒的。」/ 觉醒「我陪你们逛了四百一十二次。……这一次，我想看烟花。」

### 配角
- **宵**：祭神，狐耳少女，中二到骨子里。自称「本神」，爱发「神谕」（其实是祭典公告），每层都会以「摊主大将」的赞助人身份出场捣乱。台词：「凡人，你的签是——凶！」 **真面目（终章）**：她不是想留住今夜，**她一直在想办法让它结束**。
- **狸老板**：面具屋老板，死亡回来后的吐槽役兼商店，懒散的大叔音，什么都知道一点，什么都不说完。
- **小灯**（原巫女小孩）：迷路的小巫女，护送关卡的对象，其实是宵的「分身」，负责偷偷看三人有没有和好。
- **雨宫凛**：祭典广播站的志愿者，用广播给三人报路（无线电台词保留），冷笑话机器。
- **祭灵**（小怪）：灯笼妖、纸面具小鬼、金鱼幽灵、捞不完的水气球……全是「还没玩够」的祭典残念。可爱、吵闹，打倒时会喊「明年还来！」

## 3. 主线结构（4 层 = 4 章）

每层的固定节奏：**说书开场（古风旁白）→ 日常吐槽 → 摊位冒险 → Boss 前最轻松的一段 → Boss 第 4 阶段觉醒（配乐停，一句真心话，不插科打诨）→ 说书收尾 + 章末反转**。

### 第 1 层 · 参道 —— 「你可听说过大食切」（已接入游戏）
- 说书开场：二百年前的那一夜（古风旁白，三句话，交代刀名的荒诞由来）。
- 1-1：烟花倒带；宵宣布永不散场；凛音背着刀说「……挺好」。
- 1-2：绘马长廊，离谱愿望；凛音提前说出「左边」。
- 1-3：护送小灯；小灯认出凛音的刀：「是大食切呀。……好久不见。」
- 1-4：百目灯笼大将（般若的眼睛之一）。章鱼烧分食。
- **章末**：大将倒下，吐出一颗二百年前的铅弹，刻着「月城」。说书人：「……那一夜死去的铁炮手，姓月城。」小夜：「欸？我家祖上……是打铁炮的？」凛音的刀在鞘里低鸣。

### 第 2 层 · 夜店街 —— 「瓦版不说谎」
- 绫翻到神代家的旧瓦版：她的先祖就是给刀起名的人。「……原来丢人的名字是我家起的。」
- 射的屋大将（纵版射击）。**章末**：瓦版最后一页写着：「般若之躯，未尝化灰。」般若没死透。

### 第 3 层 · 河边花火会场 —— 「觊觎鬼力的人」
- 黑羽家的分家「黑羽宗一」（凛音的堂兄）为夺般若之力，一直在暗中帮般若吃夜晚；他堕入魔道成为中 Boss「鬼宗一」。
- 凛音坦白：她比两人早 412 夜开始循环，一直一个人在追般若。**章末（全作最重）**：般若现出真身——是朔夜。小夜看见了和自己一模一样的脸。

### 第 4 层 · 本殿 —— 「千夜一闪」
- 最终战：鬼·朔夜。她不是想吃夜晚，她是想**再逛一次那年没逛完的百夜祭**。
- 觉醒三连：小夜「没问题没问题——这次换我保护你」/ 绫「这一段，我直播给全镇看」/ 凛音拔出「千夜一闪」，把倒带的烟花和整片夜空一起斩开（**离谱到极点的奥义**）。
- 结局：朔夜被三人陪着逛完最后一个摊位，笑着消散。凛音放下了「替先祖报仇」的执念，第一次说「明天想上学」。烟花炸开，天亮。

## 4. 死亡与回家（哈迪斯式，「每一夜都算数」）
- 每次出局回到 18:00 鸟居：狸老板一句话 + 三人一句吐槽（按死因、层数、形态、连败数挑选台词，约 120 句起步）。
- 循环推进的剧情：某些对话只在第 N 次出局后出现（例：第 5 次，凛音：「左边。」第 20 次，绫：「你怎么总知道？」）。
- 宵会对 Boss 战的胜负计数：「这是你第 7 次打败本神的大将——不对，是第 6 次，上次不算。」
