====================
抄死：镜头公式
====================

视口仍是画布 W×H（横屏主体验；竖屏回退也用同一套公式）。
世界：WORLD_W = W * 4，WORLD_H = H * 2（正好 8 个视口）。不要做成无限跑图，不要做成 100 屏。
镜头：角色画在视口中央（被世界边界夹住时除外）。
camX = clamp(P.x - W/2, 0, WORLD_W - W)
camY = clamp(P.y - H/2, 0, WORLD_H - H)
可选阻尼：cam 追目标，每帧 t = min(1, dt * 10)，不要低于 6、不要做成电影缓入。默认开。
玩家夹在世界边：PLAYER_GEOMETRY 的边距对 WORLD_W/H，不再对旧的 W/H。
世界坐标是唯一逻辑坐标。碰撞、子弹、技能、场地危险都继续用 P.x/P.y 和实体 x/y，不要另造一套。
绘制世界层：ctx.translate(-camX, -camY)（或等价），画完 restore。HUD / 摇杆 / 技能钮 / 伤害字若现在是屏幕坐标就保持屏幕坐标；若现在跟实体走，跟镜头一起走。
地砖：用现有战斗背景图按镜头铺 chunk，不要新下图。缺图回退现有纯色/渐变。
刷怪：spawnEnemy 从「当前视口」四边外 pad 刷，不要再从 0..W 屏幕边刷，也不要从整个 WORLD 外缘刷（人会走很久看不见怪）。
Boss、场地危险、掉落同样相对视口或世界内合理位置，禁止刷到镜头外永久看不见。
