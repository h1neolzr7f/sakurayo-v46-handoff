# 第三方免费素材清单

本项目只收录许可明确、可离线再分发的少量通用反馈素材。角色、敌人、Boss、剧情立绘和地图主视觉不使用下列素材。

## Kenney · Interface Sounds

- 来源：https://kenney.nl/assets/interface-sounds
- 作者：Kenney
- 许可证：Creative Commons CC0 1.0
- 项目内用途：按钮、奖励、错误、Boss/阶段提示音。
- 选用文件：`click_002.ogg`、`confirmation_002.ogg`、`error_003.ogg`、`glitch_002.ogg`、`bong_001.ogg`、`open_003.ogg`、`close_002.ogg`。
- 修改：仅重命名；运行时按游戏音量设置播放。
- 许可证副本：`src/content/packs/official-feedback/art/KENNEY_INTERFACE_LICENSE.txt`。

## Kenney · Particle Pack

- 来源：https://kenney.nl/assets/particle-pack
- 作者：Kenney
- 许可证：Creative Commons CC0 1.0
- 项目内用途：枪口闪光、奖励星芒、近战斩光的附加纹理。
- 选用文件：`muzzle_04.png`、`star_06.png`、`slash_03.png`。
- 修改：重命名；运行时使用角色颜色、透明度和加色混合，不替代本体动画。
- 许可证副本：`src/content/packs/official-feedback/art/KENNEY_PARTICLE_LICENSE.txt`。

## 分发约束

- 素材全部随离线 Web/APK 本地分发，不连接外部 CDN。
- 即使反馈包脚本或素材损坏，本体仍使用程序化音效与 Canvas 特效继续运行。
- 不使用 Kenney 标识或 Logo 作为游戏品牌素材。
