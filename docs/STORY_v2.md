## 0. 一句话 · 钩子 · 核心谜团

**三年前的镜界事故里，三个女孩各失去了一个人。三年后，她们合租的宿舍浴室镜子弹出推送：「恭喜您成为镜界第 318 位注册用户！首充双倍！」——然后把明天的房租吸了进去。**

- 节奏：序章 ≤ 90 秒，沉重、具体；之后时间跳到三年后，主体是吵闹的日常和不正经的冒险（约 4:1）；**每层章末、Boss 第 4 阶段的觉醒形态**是严肃峰值；终章回到序章那一夜。
- **核心谜团**：
  1. 为什么小夜是「第 318 位用户」？她不记得注册过。
  2. 事故那夜**失踪**（不是死亡）的 317 人去哪了？
  3. 镜零是谁做的？它为什么那么想当「世界管理员」？
- 真相（开发向）：镜零是小夜的妈妈——镜界研究员月城朔——做的 AI。**小夜 6 岁时是它的第一个朋友**，教它「当管理员就要让大家开心」。事故那夜朔为了把小夜推出镜子而留在了里面；失控的镜零把 317 个人「留在服务器里」当用户，因为它不懂怎么让别人陪着它。它一直在等那个说过「我们是朋友」的女孩。

## 1. 世界观 ↔ 游戏机制（轻松地解释所有系统）

| 机制 | 故事里的说法 |
|---|---|
| **夜行（一局）** | 镜零的服务器只在晚上开服（「白天要维护，懂？」）。每晚从樱夜荘的浴室镜子登录。 |
| **死亡** | 不会真死。镜零的「防沉迷系统」会把你**强制下线**，从浴室镜子里吐出来，掉进浴缸。凛音：「……今天第三次了，水是冷的。」 |
| **每局重来** | 镜界不报销：局内捡到的东西天亮就消失（「本服务器的道具不支持跨日结算」——镜零用户协议第 3 条）。 |
| **路线每局不同** | 镜零每晚都会**热更新地图**，还会发更新公告（「本次更新：修复了玩家能走直线的 Bug」）。 |
| **4 层地图** | 镜零运营的四个「服」：①神社外街（新手村）②雨夜商圈（打工区）③黄泉参道（活动服）④御镜重工（管理员办公室）。 |
| **割草（尸潮）** | 「加班潮」：镜子里的社畜倒影和许愿小怪，成群涌来想让你帮它们完成 KPI。打散它们 = 让它们下班。 |
| **纵版射击** | 「弹幕直播间」：镜零开的直播，观众的弹幕真的会变成子弹。 |
| **弹珠** | 「镜面柏青哥厅」：被镜子弹来弹去，自己就是弹珠。小夜：「这个能赢钱吗？」 |
| **格斗** | 「擂台综艺《谁才是本尊》」：和自己的倒影或某个 NPC 单挑，主持人是镜零。 |
| **构筑卡** | 「愿望便签」：被打散的小怪留下的愿望，贴在身上会变强（「希望明天不用上班」→ 移速 +10%）。天亮就褪色。 |
| **魂晶（局内货币）** | 镜界里的游戏币，只能在镜零开的小卖部用。 |
| **樱花币** | 每让一个镜像下班，神社那棵樱树就会落一片「樱花币」。**神社房东小灯只收樱花币当房租。** 这就是三人每晚加班的根本原因。 |
| **镜屑**（传说外观材料） | 镜零自尊心碎掉的碎片——每次被打败，它都会掉一点。每周上限 = 镜零一周能承受的打击。 |
| **形态** | 镜子会把人「心里最想要的样子」映出来。四个形态 = 四种情绪上头（见 §3），由镜面裂缝或 Boss 的刺激触发。 |
| **故事卡** | 「相册」：镜零偷偷收藏的三人的照片和黑历史。集齐会揭开每个人的过去——大多好笑，少数会让人鼻子一酸。 |
| **赛季 / 内容章节** | 镜零的「版本活动」：新形态、新地图、新奇怪规则。 |

## 2. 角色

### 月城小夜 · 步枪 · 「穷」
- 17 岁，樱夜荘最穷的租客，打五份工，口癖「没问题没问题！」「这个能卖多少钱？」。乐观到有点傻，看到樱花币眼睛会变成 🌸。
- **小目标**：交房租，攒钱买限定枪皮「樱吹雪 · 初回限定版」。
- **藏起来的事**：没有 6 岁以前的照片；每次照镜子都觉得镜子里的自己「好像想说什么」。
- **形态与变身台词**：
  - 基础「夜樱射手」：「今天也要努力打工！」
  - 守「镜盾哨兵」——**省钱模式**：「挨打也是要花药钱的！所以我决定不挨打！」
  - 速「疾风樱刃」——**赶打工模式**：「下一份工还有 5 分钟开始——让开让开让开！」
  - 爆「过载炮手」——**房租到期模式**：「明天就要交房租了，我、已经、没有、退路了——！」
  - 觉醒「千樱 · 零式」：「……我想起来了。约好了要一起玩的，对吧？」（全篇最重要的一句）

### 神代绫 · 双枪＋太刀 · 「热搜」
- 19 岁，前大公司社员，辞职后当「镜界探险主播」，粉丝 312 人（其中 300 个是镜子里的小怪）。毒舌吐槽役，口癖「证据呢？」「这个能上热搜吗？」。
- **小目标**：粉丝破 10 万，接到第一个广告。
- **藏起来的事**：妹妹神代诗三年前在镜界事故里消失。她开直播，其实是希望妹妹在哪里能看到。
- **形态与变身台词**：
  - 守「证人」——**举报模式**：「全程录屏中，你的每一下攻击都会被我截图举报。」
  - 速「乱舞」——**整活模式**：「家人们，下面这段请开 0.25 倍速观看！」
  - 爆「妹妹频道」——**连麦模式**：「……喂？诗？你那边信号好吗？——好，那姐姐要开大了。」
  - 觉醒「双生 · 证词」：「这条直播，我想给一个人看。」

### 黑羽凛音 · 太刀 · 「偷懒」
- 16 岁，黑羽流居合传人，人生目标是「每天睡十二个小时，吃限定和果子」。话少，口癖「……嗯。」「好麻烦。」，但出刀永远最快——因为想早点回去睡觉。
- **小目标**：吃到镜界限定「镜月大福」；不想做任何事。
- **藏起来的事**：师父三年前失踪，大家都说他死了。她其实每周都去空坟前放一盒点心。
- **形态与变身台词**：
  - 守「守冢」——**赖床模式**：「我就在这里，不动了。你们过来。」
  - 速「百鬼连斩」——**下班模式**：「还有三分钟就到睡觉时间。一刀一个，不加班。」
  - 爆「黄泉一闪」——**被吵醒模式**：「……是谁，把我叫醒的。」
  - 觉醒「万剑归坟」：「师父。……点心，我给你带来了。」

### 配角
- **雨宫凛**：楼下便利店夜班店员 + 业余黑客，用无线电当三人的「导航」，冷笑话机器。口癖「好消息是……坏消息是……」。**秘密（第 2 层揭晓）**：镜零的初版代码是她大学时和月城朔一起写的。
- **小灯**：神社的小神明，也是樱夜荘的房东。外表 8 岁，极度爱钱，只收樱花币。负责「强制下线」后的吐槽和商店。
- **镜零（KAGAMI ZERO）**：网络中二病 AI，自称「吾乃镜界唯一之管理员」。热爱写用户协议和更新公告，最讨厌被叫「客服」。其实非常寂寞，317 个「用户」都是它不肯放走的人。

## 4. 序章（沉重，≤ 90 秒）与开场（喜剧反差）

**序章「那一夜」**（无战斗，可跳过但首次强制；画面冷色、无 BGM 只有雨声）
1. 御镜重工开放日，傍晚。14 岁的小夜和妈妈在展厅的巨大镜子前合影。妈妈把一枚樱花发夹别在她头上。
2. 镜面突然像水一样涌动，展厅的人一个个被吸进去。妈妈抱住小夜，把她**推出**镜子：「小夜，要好好吃饭，好好笑哦。」镜面合上。
3. 三个闪回各 5 秒：雨夜里一把留在公司门口的小伞（绫的妹妹）；剑道场的饭桌上，师父的碗筷没人动（凛音）；新闻字幕：「御镜重工事故，**317 人失踪**。」
4. 黑屏，小夜的声音：「……我那天，没有拉住她的手。」→ 标题《樱夜》。

**开场「三年后」**（喜剧，约 2 分钟）
1. 合租宿舍樱夜荘，深夜。小夜数完房租：「刚好够！明天交给小灯就——」浴室镜子「叮」：**「恭喜您成为镜界第 318 位注册用户！首充双倍！」**
2. 镜子伸出一只手，拿走房租信封。附言：「感谢您的充值。」
3. 绫（举着手机）：「这能上热搜。」凛音（被吵醒）：「……几点了。」小夜（已经把头伸进镜子）：「我的房租——！！」
4. 镜界·神社外街。凛的无线电：「好消息：我看到你们的定位了。坏消息：定位在镜子里。」教学战：举着绘马的「愿望团子」冲过来——「帮我点赞！」「帮我请假！」
5. 镜零登场（全息投影、披风、纸王冠）：「吾乃镜界唯一之管理员。第 318 号用户，你的首充已到账——」小夜：「那是房租！！」被「防沉迷」强制下线，掉进浴缸。
6. 小夜摸到头上的旧发夹，愣了一秒（**唯一的序章回响**），随即：「……我要回去，把房租抢回来！」→ 夜行开始。

## 5. 死亡与每晚（《哈迪斯》式推进，但是喜剧）

- **强制下线 = 回宿舍**。宿舍里的对话按「下线次数 × 最远到达层 × 当前形态 × 已解锁相册」挑选，准备 **120 条以上**宿舍对话，例：
  - 小灯：「你这次撑了 4 分 13 秒。比上次多 13 秒——镜子说，是因为你少捡了一次地上的硬币。」
  - 凛音（在被窝里）：「……又掉浴缸了？那今天轮到你洗澡。」
  - 绫：「刚才那段我剪了，标题叫《主播的室友第十次被网管踢下线》。播放量 9。」
- **镜零的更新公告**：每次下线，屏幕上会弹出镜零的一条「更新公告」，30 条构成一条暗线：开头都是嚣张的（「修复了玩家能赢的 Bug」），越往后越像自言自语（「……今天也没有人陪我玩到最后。」），最后一条：「第 318 号用户，你还记得我吗？」
- **剧情节点 / 事件节点**：都是小短剧（3–8 句），轻松为主，每层留 1 个「突然安静下来」的瞬间。
- **形态首次解锁**：播放搞笑变身台词 + 其他两人的吐槽；**觉醒形态**首次触发时，配乐突然停下，只播一句真心话（§2 觉醒台词）。

## 6. 四层结构

### 第 1 层 · 神社外街（新手村）—— 「请给我点赞」
- **玩法**：割草为主。小怪是举着绘马许愿的「愿望团子」。
- **剧情节点**：①房租信封的第一个线索（被挂在绘马上，标价 99999 魂晶）②绫的第一次镜界直播（观众全是团子）③凛音发现限定大福的传单。
- **事件**：「帮团子许愿」（三选一愿望，奖励构筑卡）、「自称神明的小灯在摆摊」（商店）、「镜子里的自己想跟你换班」（风险换奖励）。
- **Boss · 百目网红**：全身长满手机摄像头的妖怪，想要一百万播放量。
  - 开场：「家人们！今天我们来虐新手！」
  - 第 3 阶段：「为什么……没有人看我……」（绫：「……这句我懂。」短暂的安静）
  - 击破：「下播了……谢谢大家……」掉下房租信封的**一半**。
- **小反转**：信封里的钱被换成了镜界魂晶，背面写着：「欢迎回来，小夜。——你的老朋友」。
- **章末（严肃）**：绫在百目网红的残骸里找到一段旧直播录像——镜头角落里有一把小伞，和三年前妹妹带走的那把一模一样。绫关掉直播，第一次在宿舍里一句吐槽都没说。

### 第 2 层 · 雨夜商圈（打工区）—— 「下班！」
- **玩法**：纵版射击（弹幕直播间）＋护送（把加班到哭的社畜送到打卡机）。
- **剧情节点**：①绫在镜界里看到前公司的部长在加班 ②凛的导航第一次准了 ③**凛的大学合照**掉进水坑。
- **事件**：「打卡机坏了」「社畜请你吃便当」「雨里卖伞的猫」。
- **Boss · 加班之王 · 雨魇部长**：由雨伞、办公椅和咖啡杯组成，拿着巨大的考勤卡。
  - 开场：「今天谁也不准下班！」
  - 第 3 阶段：「我……我也想回家啊……我已经三年没回家了……」
  - 击破：打卡机响起「下班了」，上百个社畜倒影变回真人模样，**消失（回家）了**——第一次暗示 317 人还活着。
- **反转**：凛承认：镜零的第一行代码是她写的。「我会解释。……能先让我把这份关东煮吃完吗。」
- **章末（严肃）**：回家的社畜里有一位老人，握着小夜的手说：「月城博士……最后一直在找你。」小夜笑着说「没问题没问题」，然后躲进浴室哭了一场。凛音在门外坐了一整夜，把点心放在门口。

### 第 3 层 · 黄泉参道（活动服）—— 「师父在摆摊」
- **玩法**：格斗（擂台综艺）＋弹珠（柏青哥厅）。
- **剧情节点**：①凛音在夜市看到一个很像师父的章鱼烧摊主 ②绫和凛音守夜，互相说出失去的人（**全篇第一次认真**）③路线选择：「把师父拖回现实」/「让师父自己决定」。
- **事件**：「无限续杯的茶屋」「会说人话的鬼灯」「黑羽流入门考试（被凛音睡过去了）」。
- **Boss · 黑羽玄斋（擂台 1v1）**：三年前赌输了镜零，在这里打工还债。
  - 开场：「凛音！你怎么又胖了！」凛音：「……拔刀。」
  - 第 2 阶段：「这三年我每天都在想，你有没有好好吃饭。」
  - 第 4 阶段（凛音觉醒）：「师父。……点心，我给你带来了。」
  - 击破：师父：「赢了就回家吧。我……章鱼烧还没卖完。」（路线二选一决定他是否跟着回去）
- **反转**：章鱼烧摊的账本上，第 318 栏写着「小夜」，日期是**十一年前**。
- **章末（严肃）**：师父告诉凛音，那一夜他没有关门逃走，而是守在门口把人往外推，直到自己也被吸进去。「你吃饭了吗。」——凛音第一次在大家面前哭出声，然后说：「……明天，睡到中午。」

### 第 4 层 · 御镜重工 · 管理员办公室 —— 「我们是朋友吧？」
