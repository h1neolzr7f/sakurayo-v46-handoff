# V3.7 架构边界

为避免在正式发布前重写成熟战斗循环，V3.7 保持 `src/index.html` 为唯一运行入口，但把高风险变更隔离到明确边界：

- 素材边界：Image2 原图、处理脚本、机器清单、Android 运行资源与预览分层保存；同步时验证 168 个服饰文件。
- 存档边界：继续使用 `sakurayoV3`，主神永久强化、契约、挑战和深层纪录均位于 `save.mainGod`；普通局内强化只存在于当局 `P`。
- 测试边界：调试 API 只在 `?test=1` 开放，正式模式验证为不可见；战斗快照包含角色、服饰、瞄准、碰撞和主神状态。
- 发布边界：源码同步、素材门禁、Release 构建、Lint 和签名验证分离；签名配置不进入公开源码。
- 故障边界：图片加载保留矢量回退，旧存档缺字段按默认值合并，运行异常写入开发错误面板。

下一次真正拆分战斗代码时，应以存档迁移测试和 29 项浏览器冒烟为保护，逐步抽离数据表、渲染器和 Director，不进行一次性重写。
