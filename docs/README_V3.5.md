# 樱夜·尸潮 V3.5：三刃协奏

手机浏览器可直接运行的离线单文件肉鸽游戏。

## 运行

直接打开 `index.html`。安卓手机建议使用 Chrome、Edge 或系统浏览器。

## V3.5 主要内容

- 三名可选角色：月城小夜、神代绫、黑羽凛音。
- 三种基础战斗方式：突击步枪远程、手枪与太刀混合、纯太刀近战。
- 每名角色具有独立基础属性、普攻循环、主动技能、职业倾向和章节剧情。
- 新增衣装商店与九套皮肤。皮肤改变外观配色，并提高指定职业在升级三选一中的出现倾向。
- 衣装不会直接出售永久攻击力，仍需通过局内构筑完成职业、融合和飞升。
- 修复菜单背景层拦截角色卡片和商店按钮的问题。

## 存档

继续使用原有 `sakurayoV3` 本地存档键，可继承 V3、V3.1、V3.2、V3.3、V3.4 和 V3.4.1 的进度。首次打开 V3.5 会自动补齐角色、皮肤和已购衣装字段。
