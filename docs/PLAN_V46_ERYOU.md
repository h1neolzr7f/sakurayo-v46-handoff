# 《樱夜·尸潮》完整二游化计划

2026-08-14。当前版本 4.6.0。这不是另做一款原神，而是把**局外**做成能横着玩的二次元手游大厅，**局内**继续是离线肉鸽射击。

## 0. 一句话目标

玩家打开游戏先看到立绘和出击，而不是功能列表。寻访、名册、商店、关卡、档案都像同一款二游的房间，而不是五个抽屉。

## 1. 产品边界（不可破）

- 代码基线仍是 `src/index.html` + `src/runtime/*.js`，最终仍出单文件 HTML。
- 存档键仍是 `sakurayoV3`。新字段只写在已有对象里（寻访用 `shop40.ops`）。旧档缺字段自动补齐，禁止清档。
- 不给 `update` 再包一层。局内性能红线、实体上限、无界碰撞禁令照旧。
- 商店衣装与寻访卡**都不卖永久伤害**。卡只进名册。
- 离线：无账号、无广告、无 CDN、无强制联网。
- 三角色、14 职、28 转职、融合、三相飞升、四章 Boss、主神空间全部保留。
- Android WebView 锁横屏（`landscape`）。大厅/寻访/战场默认就是横版布局，不靠窗口先变成横的才切换。竖屏只保留射击操作并提示横持。

## 2. 玩家闭环

```
大厅看立绘
  → 寻访抽证词卡（收藏）
  → 名册点亮 / 点开看详情
  → 商店买衣与初始核心
  → 选模式出击
  → 结算回大厅
```

作弊只保留一种：大厅立绘 10 连点 → 9999 樱花币。不另开商店卖数值。
