# V3.4 不足审视与后续规划

## 仍然存在的不足

### 1. 二十八条职业分支缺少独立完整立绘

目前会改变角色配色、特效和战斗机制，但多数分支仍共用角色轮廓。后续需要为主要转职制作头像、半身立绘和三阶变身动画。

### 2. 职业树仍然藏在升级三选一中

职业进阶已经存在，但玩家不能提前完整查看路线。需要增加职业图鉴和可缩放的树状预览，明确显示成型条件、转职节点、融合对象、天敌和代价。

### 3. 数量扩充快于真人平衡验证

14 个职业、28 条分支和 18 种融合已经形成较大组合空间，但尚无足够真人数据验证通关率。后续应统计分支选择率、成型时间、阶段伤害、死亡来源与 Boss 耗时。

### 4. 只有双职业融合

三职业融合虽然更夸张，但会明显增加理解成本、特效拥挤与数值失控。当前暂时限制一局一次双职业融合；未来更适合把“三职业”做成少数隐藏超融合，而不是全排列。

### 5. 剧情吐槽仍以文字为主

选择吐槽已经能反映玩家决定，但缺少表情差分、语音、立绘切换和角色关系值。后续可让凛、小夜、镜零对同一选择产生不同态度，并在章节间保留。

### 6. 手机小屏仍可能信息过载

重叠已经修复，但 Boss 战同时出现伤害数字、场地预警、技能按钮和 HUD 时，视觉负担仍高。后续需要提供“极简 HUD”和“隐藏低价值伤害数字”选项。

### 7. 新职业的敌人克制还不够专属

现有封灵、干扰、净化等敌人可以克制新路线，但尚缺专门针对召唤物、连击节拍、魂火储存和冲刺标记的敌人。后续可增加猎宠尸、噪声尸、噬魂尸和反影忍者。

## 下一阶段优先级

1. 职业图鉴与可视化进阶树。
2. 主要三阶职业独立立绘和变身演出。
3. 新职业专属敌人与章节事件。
4. 真人数据导出与平衡面板。
5. 少量隐藏三职业超融合。
