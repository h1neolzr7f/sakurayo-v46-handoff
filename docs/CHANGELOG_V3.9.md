# 《樱夜·尸潮 V3.9：全面收敛》更新记录

## 战斗

- 冲刺新增危险窗口判定：小夜回充护盾并震退，绫触发月切追斩，凛音触发黄泉返格挡反击。
- 迅捷尸与重甲尸获得带直线预警的冲锋职责；净化尸会治疗附近单位；结界尸会主动保护 Boss。
- 太刀命中补充停顿感、震动与残光反馈，仍严格按朝向扇区判定伤害。
- 伤害数字新增关闭、精简、完整三档，默认精简。

## Boss 与主神空间

- Boss HUD 显示当前阶段规则，不再只靠增加弹幕表达阶段变化。
- 雨魇行者增加安全信道；进入信道可快速解除干扰与治疗抑制。
- 八重镜姬和轮回监察者周期适应本局最高伤害来源，要求准备副输出。
- 主神商店新增永久诅咒遗物“猩红心核”：以生命上限换取全伤害，可随兑换重置返还。

## 界面、剧情与存档

- 主菜单次要入口默认折叠为“更多设置与数据”，减少首屏按钮竞争。
- 增加角色脚底高对比辨识环、Boss 规则条、界面减法开关。
- 剧情图鉴增加当前角色跨章节选择回顾。
- 存档导入增加字段、数值边界、角色、服饰、历史长度校验。
- 本地统计版本更新为 3.9，仍然完全离线。

## 性能与验证

- 延续动态实体预算、屏外裁剪、低帧率自动降级；主神爽感优先通过成长和连锁效果实现，不再继续提高怪物硬上限。
- 通过 430×932、360×800、932×430 布局与 32 项浏览器回归，包括 240 次刷怪请求和 8 秒固定步压力测试。
- Android 版本升级为 3.9.0 / versionCode 39。
