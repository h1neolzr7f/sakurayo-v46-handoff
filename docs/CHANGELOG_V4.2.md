# V4.2.0 Mod Kit

- Content API 升级到 v2：游戏版本范围、依赖、冲突、拓扑排序与引用校验。
- 包存档迁移改为严格连续步骤；坏迁移只停用对应包并保留原数据。
- 打包器改为逐包独立编译调用；一个包的语法错误不再使整份单入口脚本无法解析。
- 新增稳定生命周期 Hook 接缝；Boss 指针、机制提示和阶段美术不再层层包装 `draw()`。
- 新增手机内 Mod Kit 面板，显示格式版本、启用包、依赖和错误原因。
- 新增 `new_content_pack.py` 脚手架与声明式模板。
- 新增依赖型官方扩展示例：道具、成就、档案和独立存档均无需修改核心。
- 图片资源继续保持本地路径校验和缺图回退；不引入 CDN。
- 保持 `sakurayoV3`、原战斗数值、正式/内测模式隔离和 Android WebView 离线入口。
- 修复扩展商店购买后没有立即重新检查扩展成就的问题。
