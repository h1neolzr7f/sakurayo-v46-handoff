# 职业进阶与融合设计

## 一、成长层级

1. **小技能阶段**：玩家试探不同路线，补充清群、单体、生存和机动能力。
2. **职业成型**：取得该职业的三项核心技能，职业名称正式显示。
3. **分支转职**：角色达到 9 级后，从两个机制方向中选择一个。
4. **职业升阶**：12 级升至二阶，15 级升至三阶。
5. **跨职融合**：两个职业满足条件后，可选择一次融合，形成新的攻击循环和代价。
6. **三相飞升**：科技、生物或灵能成为最终规则改写，可与职业融合叠加。

这种结构让玩家既能专注一条职业，也能先形成双职业再融合；不会因为早期试拿一项副路线技能就立即破坏构筑。

## 三、十八种跨职业融合

### 原有十二种

星核机甲少女、血炼剑仙、瘟炼菌海、祓魔枪巫女、元素嵌合体、磁轨剑阵、血月魔法少女、活体弹仓、雷火天师、尸解剑仙、血械猎姬、花疫魔女。

### V3.4 新增六种

1. **百鬼阴阳师**：召唤师＋巫女。灵兽获得符箓护盾，主动技能召来百鬼夜行；代价是普通枪弹变弱。
2. **影法魔女**：忍者＋魔法师。冲刺留下元素残影，苦无附着火冰雷；代价是护盾恢复下降。
3. **枪火偶像**：战场歌姬＋枪斗术。踩准节拍追加扇形弹幕，高连击进入安可齐射；低连击时伤害较弱。
4. **菌尸冥主**：死灵术士＋菌群术。感染尸体升起魂菇并传播孢子；代价是移动速度下降。
5. **血契兽王**：召唤师＋血族。使魔共享吸血，残血时兽群狂暴；代价是最大护盾下降。
6. **御剑影忍**：忍者＋修仙。冲刺时飞剑瞬移斩杀标记目标，苦无召回剑阵；代价是自然恢复下降。

## 四、组合原则

- 融合必须改变攻击循环、资源循环或走位方式，不能只增加一项百分比。
- 每个融合至少拥有一个明显强项、一个专属天敌和一个代价。
- 职业分支负责“把单职业做深”，融合负责“把两个机制接起来”。
- 飞升负责最后改写规则，因此职业、融合和飞升可以组成不同终局形态。
- 一局仅允许一次正式融合，避免手机画面和数值同时失控。
