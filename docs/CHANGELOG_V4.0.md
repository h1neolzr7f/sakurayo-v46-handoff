# 《樱夜·尸潮 V4.0：内测轮回》更新记录

## 内测后门与数据

- 正式界面不显示后门按钮；网页可用 `?beta=1`，APK 可连续点击封面副标题 7 次打开隐藏内测抽屉。
- 只有 `?beta=1` 或 `?test=1` 创建 `__SAKURAYO_BETA__` 全局接口，普通启动不暴露脚本接口。
- 可直接选择角色和章节、增加测试货币、解锁章节、满级初始核心、推进时间、直达 Boss 和切换阶段。
- 本地记录章节、角色、初始核心、诱饵、升级次数、伤害、闪避和胜负，最多保留 80 个样本并可导出汇总。

## 镜界补给商店

- 新增四种五级初始核心：火控、生存、身法、三相共鸣。
- 初始核心只装备一种；强化数值会随核心等级和当前章节同步提升。
- 新增丧尸诱饵：增加额外刷怪脉冲、延长普通波次并提高经验收益，但不突破实体预算。
- 新增穿甲弹匣、黄泉磨刀石和便携镜盾，均有明确优势与代价。
- 新增十四种职业排除符；按进度开放一至两个装备槽，不排除通用升级。

## 24 种职业融合

- 在原有 18 种融合基础上新增元素御兽使、瘟律歌姬、亡骨枪骑、纳米机忍、生体御神子、血焰术士。
- 六种融合均有双职业前置、额外条件、收益、代价、天敌、专属吐槽和可自动验证的独立战斗触发。
- 分别接入元素兽周期轰击、酸蚀节拍、魂弹连射、冲刺纳米苦无、生体祈愿回复和血焰吸血。
- 职业图鉴显示完整 24 种融合；图标已内置于离线 Web 与 Android 资源。

## 孤证试炼

- 商店可开启孤证试炼，升级时不再获得局内强化。
- 三角色均通过满级初始火控核心、零局内强化、无伤走位代理的第四章完整流程测试。
- 无伤通关终章解锁隐藏成就“孤证者”、三角色独立隐藏档案和后续开场对白。

## 冲突升级与平衡

- 新增玻璃超压弹仓、迟钝不死身、灵能短路回路、万能学徒证。
- 卡面固定显示红色风险，收益和削弱同时生效，三角色均有专属吐槽。
- 保持手枪单发伤害和射速低于步枪；依据纯初始测试提高绫第四枪月切的近战回报。
- 玩家视觉尺寸保持 96，圆形碰撞半径保持 16，视觉与判定继续解耦。

## 兼容性

- 继续使用 `sakurayoV3`；旧存档自动补齐 V4.0 商店、内测统计和隐藏剧情字段。
- Android 版本升级为 4.0.0 / versionCode 40。
