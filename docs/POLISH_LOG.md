# POLISH_LOG：持续打磨记录

## 美术方向（2026-10-11 13:43 确定，以此为准）
**中式科技二次元，主要参考《崩坏3》。** 之前的“和风”和“国风”方向都已废弃，相关元素已全部替换。
- **主体**：科幻机能风。硬朗的切角面板、斜切块、发光描边、HUD 线框和刻度、全息扫描线、编号文字（SKR-01、OPS-01 等）、数据流，加少量故障风（glitch）点缀。
- **崩三特征**：高对比的斜切标题条；大号斜体英文配中文；菱形和六边形图标框；进入关卡时斜切闪屏转场；加载时显示进度条和词条。
- **中式元素只做点缀**：少量汉字和纹样叠在科技面板上，例如印章式编号、线框化的云纹。
- **配色**：深蓝黑底（#070c18），青蓝发光为主（#38e1ff），樱粉（#ff6fae）和朱红（#ff3b4e）作强调，金色（#ffc94a）只用于稀有度。
- **部件规范**：红点 → 发光菱形提示点（`.sy-dot`）；角标 → 斜切标签（`.sy-tag`）；面板角花 → HUD 拐角线框；转场 → 斜切闪屏加扫描线；点击粒子 → 发光碎片（保留少量樱花瓣作点缀）。
- **字体**：英文用 Rajdhani Bold 斜体，中文用 Noto Sans SC（思源黑体同源）800 字重，两者都是 OFL 许可，并做了子集化（中文 1829 字，272KB；英文 9KB）。
- **素材**：图标、入口插画、页头横幅一律用中转站 gpt-image-2 按此风格生成；参考作品的图片只看不用。

## 第 1 轮（2026-10-11）：UI、界面装修，加上 v24 复查

### 评审方法
用二游玩家的挑剔眼光，对照以下作品，逐个界面截图评审：崩铁、蓝档、方舟、绝区零、学院偶像大师（UI）；东方、拳皇、Skullgirls（战斗表现）；吸血鬼幸存者、哈迪斯（关卡节奏）。截图工具是 `tools/shoot_ui.mjs`。

### 前 10 个最影响体验的问题（按影响排序）
1. **按钮“死”的**：没有悬停、按下、回弹，也没有点击音。二游的主按钮每次点击都有缩放、光泽和音效反馈（蓝档、崩铁）。
2. **页面切换硬切**：抽屉和面板直接出现，没有转场。蓝档有“什亭之箱”扫屏，方舟有斜切幕。
3. **点击没有视觉反馈**：蓝档的 FX_Touch（光环 + 碎片）是品牌记忆点，而我们点哪儿都没反应。
4. **图标风格不统一**：大厅入口图标的线宽、透视、配色各不相同。
5. **红点是纯色圆点**，没有设计感。（第 2 轮已改为发光菱形提示点。）
6. **面板是纯色块**：没有折角、纹样、美术字标题，精致感不够（崩铁面板有细金线角花，学马仕有手账风贴纸）。
7. **加载和空状态是死画面**：只有一行字，没有角色陪伴感。
8. **货币数字瞬间跳变**：获得或花费时没有滚动，看不出收益感。
9. **获得奖励只有一条 toast**：大奖和小奖一个待遇，没有按稀有度的光效。
10. **大厅永远一个时段**：看板娘场景没有昼夜感（崩铁、原神大厅都随时间变化）。

另外记录、下轮处理：格斗受击长时间停在同一帧（本轮已修）；STG 自机待机帧太少（本轮已按 LuaSTG 规格补齐）。

### 本轮做了什么
- **设计令牌**：`--sy-sp-*`（间距）、`--sy-r-*`（圆角）、`--sy-fs-*`（字号）、`--sy-c-*`（颜色）、`--sy-ease-*` 和 `--sy-t-*`（动效）、`--sy-font-title`。新加的打磨组件全部只用令牌。
- **按钮**：悬停上浮 2px、按下压缩到 0.95、松开回弹（back.out），配 WebAudio 点击音和面板打开铃音；主按钮悬停时有光泽扫过。
- **樱花粒子**：点击时出现光环和花瓣，鼠标移动时有花瓣拖尾。粒子层是独立 canvas，空闲时停止循环；在战斗画布上点击不触发；遵守 `prefers-reduced-motion`。
- **转场**：打开入口时樱色斜切幕扫过；抽屉、夜行地图、射的面板有淡入上浮动画。
- **图标套图**：9 个大厅入口图标用 gpt-image-2 链式重绘（先出关卡图标定风格，其余以它为参考），文件在 `art/ui/nav/*.webp`。
- **角标和红点**：第 1 轮做的灯笼红点和樱花、狐狸角标属于和风，已在第 2 轮替换为菱形提示点和斜切标签，旧素材已删除。
- **面板**：第 1 轮的金线角花已在第 2 轮替换为 HUD 拐角线框。
- **加载和空状态**：Q 版小人（复用 STG 的 8 帧待机）配一句台词；空列表自动替换成小人。
- **数字滚动**：樱花币变化时做 0.6s 的 ease-out 滚动，增加时金色发光、减少时偏红。
- **奖励弹窗**：`SakurayoPolish.reward({rarity})`，按 N、R、SR、SSR 分档显示旋转光芒、外发光和花瓣量；已接入射的中奖。
- **大厅昼夜**：拂晓、白昼、黄昏、百夜四个时段，用 soft-light 叠色并在角落显示时段标签，每分钟检查一次。
- **前后对比**：截图在 `shots/polish1/{before,after,compare}/`，录像在 `shots/polish1/ui-before.mp4` 和 `ui-after.mp4`。

### 修复的 bug
- 第 1 轮的数字滚动：MutationObserver 是异步回调，会把自己写入的中间值当成新变化，导致 rAF 链指数增长、页面卡死（射的中奖时必现）。现在记录最后写入的文本并忽略它，问题已修复。

## 验收标准（2026-10-11 起，所有界面都适用）
**方法**：每个界面与《崩坏3》的同类界面并排对照，按 6 个维度打 1～5 分。崩三的同类界面记为 5 分。
**完成线**：每一项都要 ≥ 4 分。任何一项 ≤ 3 分，也就是明显不如崩三，就不算完成，必须进入下一轮。

| 维度 | 4 分的最低要求 |
|---|---|
| 质感 | 面板有切角、发光描边、内高光、扫描线或纹理中的至少 3 种；不出现纯色块 |
| 层次 | 背景、角色、面板、前景特效至少 4 层，有景深（模糊、压暗或视差） |
| 动效 | 进场、退场、切换都有缓动；常驻界面有环境动态（粒子或扫描），不出现静止画面 |
| 反馈 | 按下要有 ≥ 3 层反馈（形变、音效、粒子或光效）；关键按钮要有专属反馈 |
| 特色 | 至少使用一个游戏独有的视觉符号（SKR 樱印、樱瓣线框），不能只是通用科幻 UI |
| 细节 | 编号文字、刻度、英文副标题、对齐与间距都走设计令牌；没有错位、溢出或默认样式残留 |

## 第 3 轮（特色演出层，`src/runtime/sakurayo-ui-fx.js`）
- **SKR 樱印**：五瓣樱花科技化——切角花瓣线框、六边形核心、60 格刻度环、双向慢转。出现在大厅水印、加载页中心和结算面板。
- **大厅动态背景**：Canvas2D 绘制。六边形网格随斜向扫描带点亮，加上上升的数据光点、线框樱瓣和水平扫描线。
- **3D 视差与镜头推拉**：鼠标或陀螺仪驱动背景、角色、面板、Logo 四层反向位移，面板绕 Y 轴 ±4°；打开子页面时大厅后退到 0.94、模糊并压暗，子页面从 Z 轴 +140px 推入。
- **出击键多层反馈**：形变（第 1 轮）→ 双色菱形冲击波 → 故障闪烁（色相、反相、位移）→ 全屏斜切闪光加扫描线 → 音效。
- **加载演出**：樱印、真实进度条（按图片加载比例计算，单调递增）、百分比、每 1 秒轮换一条词条提示。
- **结算演出**：面板从左向右切入，双色光带扫过，评级字从 3.2 倍砸下并带错位描边，数据行依次滑入，数字从 0 滚动到最终值，按钮改为斜切样式。
- **角色出场展示**：切换角色时，斜切黑带切入，立绘从右侧滑入，编号和斜体角色名依次出现，1.4 秒后淡出。
- **性能与降级**：不用 WebGL，全部用 Canvas2D 和 CSS，安卓 WebView 都能跑；DPR 上限 1.5，30fps 上限；大厅隐藏或页面后台时暂停；≤4 核或 ≤3GB 内存的设备粒子减半；`prefers-reduced-motion` 或“减弱特效”开启时关闭视差和旋转。实测 headless（无 GPU）平均帧耗时 23ms。
- **参考**：Juice it or Lose it 的反馈叠加思路；ba-click-fx（MIT）的光环加碎片分层；崩三的斜切转场、结算砸字和角色切换演出只参考了节奏与构图，没有使用任何素材。
- **修复**：按钮微动效改用独立的 `scale` / `translate` 属性。之前用 `transform` 会覆盖地图节点自身的定位，导致节点点击落空，`levels_smoke` 因此失败。

## 色彩体系 v2（2026-10-11 15:30 起，最高优先级反馈）

用户问题 → 根因 → 处理：
1. 粉、红、青、紫混用，没有主次 → 四种饱和色同时当主色用 → 只保留一个主色（靛蓝 #87b1fd，取自立绘和场景的主色相）和一个强调色（樱粉），红色只作危险色，金色只作稀有度色。
2. 面板和背景明度差太小 → 面板是半透明的青黑叠在场景上 → 中性色阶 n0–n6 按 OKLCH 明度阶梯排列，背景、容器、悬浮分三层（n0/n1/n2），描边改中性 n3。
3. 出击键的红色和立绘、场景冲突 → 出击键改成主色渐变叠插画，入口插画统一调色（青→靛蓝，红→樱粉降饱和）。
4. 底栏和卡片颜色不统一 → 底栏、卡片、旧界面的按钮、页签、钱包、提示条都改走令牌：行动按钮用主色实心，页签用中性底、选中时主色描边。
