# 第一期无人值守开工单

给「一条 Cloud Agent / 一个长会话」用。人只参与 3 次。达到的是已锁定的第一期，不是 66 张全画完。

## 你要露脸的 3 次

1. **开工**：回「按这个开工」或把下面「开工提示词」贴进新的 Cloud Agent。  
2. **认人抽查（可跳）**：14 张基础封面缩略图，你只打「过 / 哪几张重画」。超过 24 小时不回，Agent 按自检通过继续，不堵。  
3. **收工**：PR 绿了、门 C 过了，你点合并或下包。Agent 不准自己升 4.6.1、不准卸正式包、不准交 APK/密钥。

中间不要再拍数字、池名、卖不卖伤害。那些已经锁死。

## Agent 自己做的流水线

同一仓库、同一分支（`cursor/mirror-gacha-longrun-5030` 或从其再开 `cursor/autorun-phase1-5030`）。
