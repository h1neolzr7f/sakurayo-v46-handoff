# V3.7 更新记录

## 主神空间

- 增加 T4 无限回廊，通关后逐层提高敌方强度、持续时间与奖励。
- 每轮生成三份有代价的随机契约，并随机分配一个额外奖励挑战。
- 主神兑换支持全额重置；关卡进度、契约记录和深层纪录不清除。
- 主神奖励、契约、挑战和深度写入独立存档字段，不污染普通四章数值。

## 角色与美术

- 完成霓虹战术风衣、绯血生体礼服、星辉灵能裙装、剑道部夜羽织、末日舞台演出服、炼金防污围裙、百鬼召唤睡衣、镜夜祭典巫女服。
- 三名角色每套均提供头像、对话图与五态 Q 版动画，共 24 组、168 个透明 WebP。
- 商店与战斗按当前角色/服饰加载真实素材，加载失败时保留矢量回退。

## 易用性与表现

- 增加首次战斗教程与可重复打开的新手说明。
- 职业图鉴展示分支和进阶等级，并支持职业、融合、飞升与前置条件搜索。
- 增加最近 30 局统计、胜率/平均等级/击破汇总和本地 JSON 导出。
- 增加总音量、战斗音效、氛围音乐、震动和特效强度设置。
- 增加 Boss 独立阶段符号和主神监察者轮回符文。

## 发布工程

- Android 版本升级为 3.7.0 / versionCode 37。
- 增加服饰清单、168 文件解码检查和 Android 同步门禁。
- Release APK 使用项目专用 RSA 3072 正式签名，并通过 v1/v2 签名验证。
