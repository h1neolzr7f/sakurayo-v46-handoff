# 《樱夜·尸潮》美术圣经

## 1. 核心视觉命题

**末世都市 × 夜樱 × 二次元作战 × 企业实验区。**

画面必须同时传达两件事：

1. 这是有角色吸引力、收藏欲和仪式感的二次元游戏；
2. 这是城市已经失守、人格被企业回收、尸潮仍在运转的危险世界。

禁止把项目做成随机赛博朋克、纯粉萌系、中世纪高魔或现成商业二游的拼贴。霓虹只是雨夜企业区的光源；樱花既是品牌符号，也是“短暂生命与可复制人格”的叙事隐喻。

## 2. 视觉层级

| 层级 | 目标 | 处理 |
|---|---|---|
| 角色 | 第一眼识别身份与武器 | 清晰脸部、稳定发色、明确武器轮廓 |
| 主操作 | 一秒内找到出击/选择/关闭 | 樱粉主操作、暖金稀有操作、42px 以上触控区 |
| 场景 | 建立章节与世界观 | 深色、留出战斗安全区，不与弹幕争亮度 |
| 系统信息 | 可读但不压角色 | 深紫面板、青色系统提示、暖金奖励 |
| 装饰 | 增加二游质感 | 少量花瓣、镜片、封条和细金线，不堆毛玻璃 |

正式中文、英文、数字、品牌名全部由 HTML/Canvas 绘制。位图不得带文字、字母、数字、水印或伪 UI。

## 3. 三名主角

### 3.1 月城小夜 / `sayo`

- **定位：**远程压制，镜界巫女，玩家的第一视觉中心。
- **脸与气质：**年轻女性，柔和鹅蛋脸；克制、警觉，吐槽时有轻微反差，不做幼态大头。
- **发型：**深紫长发或高束长发，额前整齐碎刘海；右侧樱花结饰。
- **眼睛：**紫瞳。
- **服装：**白色短羽织、深紫作战内搭、樱粉封边与花纹、黑色长袜和战术靴。
- **武器：**白色紧凑型樱花突击步枪；长枪管、黑色机匣细节、樱粉花纹。不得变成法杖、狙击枪或双枪。
- **色板：**`#F6F1F7` / `#2B2142` / `#E969A7` / `#6B4A87`。
- **轮廓关键词：**白色宽袖 + 横向步枪 + 紫色长发。

### 3.2 神代绫 / `aya`

- **定位：**手枪与太刀切换，企业追缉者，速度与责任感。
- **脸与气质：**锐利但不冷漠；动作利落，笑容少而真。
- **发型：**银白短发，侧编发或小束带；禁止长白直发覆盖凛音轮廓。
- **眼睛：**亮蓝瞳。
- **服装：**白/黑企业战术制服，钴蓝领带与封边，短裙或短战术下装，黑色枪套。
- **武器：**一把紧凑型黑色手枪 + 一把蓝黑月光太刀。两件武器同时出现时必须合理佩挂，不增加第三把刀。
- **色板：**`#F3F6FA` / `#181C29` / `#3D82D8` / `#87C8F2`。
- **轮廓关键词：**银白短发 + 举枪手 + 腰间蓝色太刀。

### 3.3 黑羽凛音 / `rion`

- **定位：**纯太刀近战，黄泉流继承者，最强风险回报。
- **脸与气质：**沉静、锐利、重承诺；不是哥特大小姐，也不是嗜血狂战士。
- **发型：**黑色长直发，暗红内层或发带；长发形成明显向外的刀势轮廓。
- **眼睛：**赤红或琥珀红瞳。
- **服装：**黑色现代剑道制服与短羽织，暗红滚边、金属家纹少量点缀，黑色战术靴。
- **武器：**单把黑红太刀；刀镡与缠柄清晰。禁止持枪、双刀或巨剑。
- **色板：**`#17141B` / `#3A1A25` / `#B53C55` / `#D79A73`。
- **轮廓关键词：**黑长发 + 暗红羽织 + 单把横向太刀。

## 4. 角色素材一致性

同一角色的大厅站桩、头像、卡面、剧情表情、战斗 Q 版必须共享：

- 发色、刘海结构、瞳色；
- 服装主轮廓和身份色；
- 武器类别和主要结构；
- 年龄感与脸型。

允许随用途改变比例：

- **大厅/寻访：**6.5–7.5 头身，完整头部与脚部，武器清晰；
- **剧情表情：**胸像，脸部优先；
- **战斗：**约 2.25 头身 Q 版，96×96 逻辑绘制盒；
- **卡面：**3:4 竖构图，可使用半身或全身，但不得改变人物身份。

不同用途不能像不同角色。飞升、职业、融合衣装可以重做服装，但脸、发型、瞳色和武器身份必须保留。

## 5. 场景语言

### 第一章：神社外街

- 月下石板、鸟居、灯笼、夜樱、企业封条。
- 主色深紫与樱粉，暖灯只作路径锚点。

### 第二章：雨夜商圈

- 湿润沥青、企业霓虹、停尸车辆、监控与封锁线。
- 主色蓝青与品红；避免满屏高亮招牌。

### 第三章：黄泉剑冢

- 破败道场、石灯、插剑、亡者名牌、薄雾。
- 主色石灰、暗紫、冷白；剑与角色必须从背景中分离。

### 第四章：镜界核心

- 碎镜、人格存储舱、企业核心线路、悬浮反射面。
- 主色深紫、冷白、少量暖金；镜片不能造成弹幕误读。

### 主神空间

- 白色监管回廊与虚空断层，几何秩序压过自然元素。
- 不等同普通赛博空间；必须有审判、权限和轮回的压迫感。

## 6. UI 系统

### 颜色职责

- 背景：`#080713` / `#100B1E`
- 面板：`#120E27`，必要时 92–96% 不透明
- 主操作：樱粉 `#F35AA6`
- 稀有/确认：暖金 `#F2C75D`
- 系统/路线：青色 `#69DDF2`
- 危险：珊瑚红 `#FF5B74`
- 正文：`#FFF7FB`
- 次级文字：`#CFC4DF`

### 材质

- 使用深色实体面板、细金线、局部渐变和轻微内高光。
- 横屏禁止整页大面积 `backdrop-filter`；移动端不叠多层模糊和阴影。
- 关闭键、主按钮、模式选择必须稳定，不因背景明暗失去可读性。

### 页面角色

- **大厅：**角色与“出击”是主角，五房是次级导航。
- **寻访：**场景、当前角色、保底和抽取动作形成仪式。
- **名册：**16 张证词像收藏墙；锁卡不剧透。
- **商店：**商品卡统一，但不让衣装误解为数值售卖。
- **关卡：**先选模式，再选章节；锁定状态一眼可辨。
- **档案：**四个房间属于同一系统，图标与正文层级一致。

## 7. 卡面规则

- 竖向 3:4，主视觉安全区离边缘至少 6%。
- 不烘焙卡名、稀有度、NEW、数量；这些由 UI 叠加。
- N：蓝灰/月白边；R：青绿边；SR：紫色边；SSR：暖金边。位图本身不必画框，避免重复。
- 同一套卡的渲染精度、线稿和肤色一致。
- 人物卡必须遵守角色设定；场景/证物卡必须能对应四章或主神叙事。
- 禁止与世界观无关的婚纱、泳装、随机机甲、欧洲城堡和写实男性时尚肖像。

## 8. 战斗表现

- 普通战斗不依靠常驻发光辨识角色；使用高对比轮廓、地面影子、武器方向和身份色短反馈。
- 高亮只用于技能、完美闪避、融合、飞升、Boss 转阶段和场地危险。
- 打击反馈优先级：命中时机 > 武器方向 > 伤害数字 > 粒子数量。
- VFX 生命周期短、数量受限；不得突破敌人、子弹、Boss 弹、召唤物、伤害字和粒子预算。
- 融合色：
  - 星核机甲：青蓝；
  - 祓魔枪巫女：樱粉/金；
  - 血炼剑仙：血红；
  - 御剑影忍：紫黑；
  - 百鬼阴阳师：青绿；
  - 枪火偶像：粉金。

## 9. 图片生产与验收

每张关键图片必须完成：

1. 依据本文件和对应角色现有身份图生成/编辑；
2. 检查手指、眼睛、脸型、武器结构、透视、重复肢体；
3. 检查无文字、无水印、无伪 UI；
4. 透明图检查四角、发丝、枪口、刀鞘和鞋底；
5. 转为运行时 WebP，保持正确尺寸；
6. 接入游戏后在 932×430 实际截图；
7. 检查裁切、对比度、安全区、按钮遮挡和角色一致性；
8. 不合格就返工，第一张图不是默认最终稿。

图片失败必须回退到已有本地资产或程序绘制，不能联网加载，也不能借用错误角色/融合的图片。
