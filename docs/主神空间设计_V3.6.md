# 主神空间 V3.6 设计与规则

## 模式定位

主神空间是通关第四章后开放的独立高难挑战，不属于普通五章，也不会修改普通剧情结局。

- T1 回廊试炼：经验 2.8 倍，敌方强度 1.72 倍。
- T2 权能试炼：经验 3.2 倍，敌方强度 2.02 倍。
- T3 轮回试炼：经验 3.6 倍，敌方强度 2.34 倍。
- 主神空间拥有开局轮回武装、额外弹幕、穿透、护盾、重抽和每级成长奖励。
- Boss 为“主神投影·轮回监察者”，保留四阶段机制并随层级额外强化生命和伤害。

## 两套成长的边界

局内成长包括职业、小技能、转职、融合、飞升和本轮主神灌注。它们在每次结算后清空。

跨轮回成长只来自主神兑换大厅，消耗奖励点购买，并且只在主神空间生效：

- 基础权能：伤害、生命、时间压缩、经验共鸣、命运偏斜。
- 血统与灵能：再生序列、心灵链接芯片、本能解锁序列、镜核原液变异、零时差感应环。
- 职业与技法：枪剑同调、多重魔法回路、英灵召唤契约、轮回队长印。
- 特殊道具：折叠军械空间戒、因果替身人偶、支线剧情权限钥匙、监管防弹织层、裁决投针、诅咒遗物·猩红心核。

第一部概念对照与取舍见 [主神兑换_第一部对照.md](主神兑换_第一部对照.md)。

主神兑换不会带入普通四章，避免破坏已有难度规划。

## 独立剧情

- 开场：角色进入白色轮回监管大厅，主神发布生存任务。
- 32%：第一次契约，在安全修复和高危增伤之间选择。
- 64%：删除未来预测，在战斗灌注和削弱 Boss 适应之间选择。
- Boss 75% / 50% / 25%：依次开放复制短板、失败记录训练和最终权限。
- 结算：奖励点与兑换被保留；凛发现现实一分钟内出现了数百次死亡校验，留下主神身份伏笔。

## 武器规则

- 枪械继续自动锁定最近敌人。
- 武器角度与主弹道使用同一个弧度，枪身、枪口和子弹严格共线。
- 移动方向不会覆盖攻击方向。
- 太刀同时检查攻击距离与面向夹角；普通斩为前方约 120 度，第三刀约 190 度。
- 身后或扇形外敌人不会受到刀伤。
