# 基础 14 文案

封面：`android-app/app/src/main/assets/game/art/gacha/{id}.webp`（768×1024）。第一人称「我」。不写伤害数字。认人未接线前不要把这些 id 写进存档逻辑。

### school_shrine
标题：未归·巫女小夜
封面文件：gacha/school_shrine.webp
认人三件套：紫黑发 / 夜樱步枪 / 符没封住镜核
稀有度：SR · 小夜
1 她是谁：我是神社那一夜的小夜。符纸写着我的名字，镜核比名字先亮。
2 一路怎么走：我把封条一层层贴上步枪，贴上鸟居，贴上自己的袖口。外面的备份还在扫地。
3 怎么失败：符烧完了，镜核还在转。裂口从镜里爬到我肩上，朱砂写成「失败」。
4 临终：我仍举着枪。封条先落地。
