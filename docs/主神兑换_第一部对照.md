# 主神兑换对照：《无限恐怖》第一部

2026-08-17。只借鉴高层概念，不照搬原著角色、桥段或专有道具名。兑换仍只在主神空间生效，不卖进普通四章。

## 范围

“第一部”按原著第一季完整故事弧理解，相对续作《无限进化》：

1. 生化危机 1
2. 死神来了
3. 生化危机 2
4. 神鬼传奇
5. 生化危机 3（终战）

原著后来把异形、咒怨等插入同一长线。血族子爵的正式兑换在异形篇，严格说已超出最早几卷；生化二恶魔队复制体已经展示血族能力，故只作概念来源，不进货架原名。

## 主神核心循环（模板 / 碎片 / 衍生）

百分比货架只做保底。真正的轮回身份在 `save.mainGod.core`：

| 层 | 存档 | 玩家动作 |
|---|---|---|
| 轮回模板 | `core.mecha/crimson/qi/star/titan` + `eqMain/eqSub` | 花奖励点兑换，装主/副槽 |
| 基因锁碎片 | `core.shards` + `lockSurvive/lockControl/lockSpecial` | 通关给碎片，点生存/控制/特化 |
| 衍生 | 不进货架 | 猩红＋气机＋潜能特化 → 心核激荡；控制锁 → 念丝偏转 |

模板只在主神空间生效。主槽吃满，副槽约 55%，买了没装备约 28%。

通关碎片：T1+1 / T2+2 / T3+3 / 无限回廊 `1+floor(depth/8)`。失败但 Boss 已到第三阶段仍给 1。

不把「爆炸」「念动力」写成商品名。它们是模板相冲后的衍生。
