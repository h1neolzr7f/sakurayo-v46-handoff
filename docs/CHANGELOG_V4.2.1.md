# V4.2.1 战场光照收敛

- 普通关卡默认采用“柔和”发光，不改变战斗数值、碰撞和实体预算。
- 晶核、普通子弹、枪口、飞剑、宠物、斩击、精英环和角色外发光改用统一光照倍率。
- Boss 战、主神空间和关键技能保留更高视觉能级，形成普通攻击 < 技能 < Boss 转阶段的层级。
