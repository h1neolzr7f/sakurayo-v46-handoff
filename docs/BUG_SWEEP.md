# 截图巡检与修复记录（2026-10-11 起）

巡检脚本：`node tools/sweep.mjs <输出目录> [场景名过滤]`
- 23 个场景：大厅、10 个抽屉子页、衣橱、夜行、夜行地图、主线关卡地图、射的、AVG 剧情、割草战斗、升级弹窗、结算、Boss 三选一、弹幕、格斗。
- 每个场景截三种尺寸：1280×720、844×390、390×844。战斗类场景切到实时时钟，每种尺寸取 3 帧。
- 同时导出 `report.json`：控制台报错、资源 404、文字被裁切、按钮出屏、坏图、占位文字、1 秒采样帧率。
