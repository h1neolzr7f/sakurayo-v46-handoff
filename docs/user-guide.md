# 怎么玩

当前版本 **v4.4.6**。玩家优先下 [Releases](https://github.com/h1neolzr7f/sakurayo-zombietide/releases/tag/v4.4.6)，不要从源码里找 APK。

## 手机

1. 下载 `Sakurayo-ZombieTide-v4.4.6-android.apk`。
2. 用发布说明中的 SHA-256 核对。
3. 允许未知来源后安装。覆盖安装旧正式包会保留存档。
4. 打开应用，选角色，左手摇杆移动，右侧冲刺和技能。

最低 Android 6.0。正式包锁横屏，对标二游大厅和宽战场。不做竖版。

## 电脑

克隆仓库后用 Chrome / Edge 打开 `src/index.html`。键盘和鼠标能玩，但操作是按手机触控设计的。

存档写在本机 `localStorage`，键名 `sakurayoV3`。换浏览器等于换档。

## 一局在干什么

1. 选月城小夜、神代绫或黑羽凛音。
2. 在四章里清尸潮、捡经验、三选一升级。
3. 职业成型后选转职分支；满足条件可融合一次。
4. 终局可选科技 / 生物 / 灵能飞升。
5. Boss 在 75%、50%、25% 转阶段。打完看过场和结算。

主神空间是独立高难轮回，不走普通四章奖励。里面买的强化跨局保留，局内升级不带进四章。

## 商店

樱花币买衣装。衣装只改外观和职业出现倾向，不加永久伤害。

## 文字挡操作时

剧情、抉择、升级、暂停、结算会暂停并收起电台和系统提示。关掉模态后，排队的字再继续。如果文字叠在按钮上，先关最上层的那一块。

## 旧档

不要手动清应用数据来「升级」。缺的新字段会在读档时补上。只有在你自己决定重开账号时才清数据。
