# 樱夜·尸潮 V3.7：主神轮回

V3.7 是在 V3.6 可玩版本上的正式化更新。保留三名角色、四章剧情、14 个职业、职业进阶、融合与三相飞升，并完成主神空间长线循环、真实服饰素材、教程、统计、声音设置和正式 Android 签名发布。

## 运行

- Android：安装 `樱夜尸潮_V3.7_主神轮回_正式版.apk`。
- 浏览器开发入口：打开 `src/index.html`。所有图片均为本地资源，不请求网络。
- 存档键继续使用 `sakurayoV3`，旧版缺失字段会自动迁移。

## V3.7 核心内容

- 主神试炼 T1–T3 与 T4 无限回廊；三选一随机契约、附加挑战、奖励点、兑换重置和跨轮回永久强化。
- 8 套非默认服饰 × 3 名角色，每套含头像、对话和待机/移动/攻击/受击/冲刺五态 Q 版素材。
- 首次开局四页教程、职业树搜索、最近 30 局统计与 JSON 导出。
- 步枪、手枪、太刀独立音色，Boss 阶段氛围层、震动与特效强度设置。
- 四章 Boss 与主神监察者具有不同的阶段视觉身份。
- 版本号 3.7.0（37），使用项目专用 3072 位 RSA 正式签名。

## 签名

签名保管包必须离线保存。后续更新相同包名 `com.sakurayo.zombietide` 时必须沿用其中的 JKS、别名和口令。
