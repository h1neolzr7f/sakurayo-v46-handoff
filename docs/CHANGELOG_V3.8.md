# 《樱夜·尸潮 V3.8：镜界证词》更新记录

## 剧情

- 重写三名角色四章开场，共 48 段角色专属主线对白。
- 小夜线围绕“复制人格是否拥有选择生死的权利”。
- 神代绫线围绕“签名者责任与妹妹拒绝被救援的权利”。
- 黑羽凛音线围绕“继承记忆是否等于继承一个人，以及传统能否被改写”。
- 选择会按角色跨章节保存，并改变后续开场回声、Boss 转阶段对白和最终结局。
- 每名角色新增三段终局 Boss 回应，避免只替换角色姓名。

## 战斗美术与信息层

- 新增 12 个 Q 版敌人素材：普通、迅捷、坦克、远程、自爆、结界、干扰、净化、幽魂、腐败祭司、封灵和精英。
- 新增 16 个 Boss 阶段素材，四章 Boss 在 75%、50%、25% 血量阈值真正更换外观。
- 新素材加载失败时自动使用旧 Canvas 绘制，避免角色或怪物消失。
- Boss 离开画面时显示方向和距离箭头。
- 场地攻击改为“预警—锁定倒计时—爆发”三阶段表现。
- HUD 构筑说明默认收起，点击可以展开，减少手机战斗区遮挡。
- 敌人上限改为按屏幕面积和画质动态计算：430×932 普通关卡标准约 82 只、省电约 56 只；主神空间额外保留约 10 只怪海预算。
- 敌人超过 56/74 只时仅缩小视觉贴图，不改变碰撞体和伤害；屏幕外敌人不再提交 Canvas 绘制。
- 子弹、敌弹、粒子和晶核继续分别使用独立硬上限，防止任何一种实体拖垮整帧。

## UI 与存档

- 升级卡显示当前值到升级后数值、局内重置提示和冲突风险。
- 职业图鉴与主神商店新增分类标签。
- 主菜单新增存档管理：生成、复制、下载和导入 JSON。
- 四个工具按钮针对窄屏重新排版，不再拆成两行文字。
- 声音设置页新增“战斗界面大小：标准/紧凑”，可缩小顶部 HUD、任务条和暂停按钮。
- 本地统计版本更新为 3.8。

## 兼容性

- 继续使用 `sakurayoV3` 存档键，可继承 V3、V3.4、V3.5、V3.6、V3.7 的关卡、货币、服饰和主神强化。
- Android 版本：3.8.0，versionCode 38。
- 沿用 V3.7 正式签名，可覆盖安装升级。
