# Image2 全量美术规格（Android APK）

## 1. 目标与风格锁定

用户提供的 `Image_1783684703372.jpg` 只作为美术风格参考：干净日系二次元赛璐璐插画、细深色轮廓、暖色柔和肤色、两段式平涂阴影、可爱且清晰的轮廓。不得复制参考人物的身份、服装、猫耳、武器或构图。

第二参考图 `assets/reference/战斗与成长界面概念图.png` 只用于手机游戏构图、战斗比例和信息密度，不用于复制 UI 文本。

所有生成任务固定：

- 模型：`gpt-image-2`
- 质量：`high`
- 输出：PNG 图集，后处理为 WebP
- 禁止：文字、字母、数字、标签、签名、水印、跨格元素
- 网格：严格等分、row-major、单格单对象、8% 安全边距

## 4. 透明与切图标准

角色使用绿色色键 `#00ff00`；僵尸、晶体等可能含绿色的对象使用橙色色键 `#ff7a00`。背景必须完全单色，无阴影、渐变、地面、反射、雾、外溢光晕或纹理。

`tools/image2/postprocess_assets.py` 的处理顺序：

1. `remove_chroma_key.py` 自动读取边缘色键。
2. soft matte + despill 处理抗锯齿边缘。
3. 按固定网格切分。
4. 按 alpha 包围盒紧裁。
5. 等比缩放到统一透明画布。
6. 保存 lossless WebP。
7. 校验透明四角、主体覆盖率和输出尺寸。
8. 生成联系表和 JSON 报告。

合成 QA 已验证 4/4 透明素材：四角 alpha 均为 0，主体覆盖率为 43.034%–46.443%，预览位于 `assets/image2/previews/synthetic_chroma_qa.png`。
