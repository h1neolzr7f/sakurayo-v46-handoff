# 樱夜战术终端与常规大厅服务

用户明确纠正上一版大厅，要求明日方舟那种类型的前端，并补齐邮箱等常规二游功能，授权自主完成与测试。

视觉：用户在第一张概念图后指出右侧太满，进一步指定崩坏3类型。最终采用 docs/screenshots/tactical-concept.webp 的疏朗构图：助理立绘左侧偏中、右侧仅干员/装备整备/出击三组浮动操作；六个小图标在右下，左下放活动横幅、三角色切换、任务和签到。邮箱/公告/设置位于资源顶栏。冷灰场景、白色图标、冷蓝强调，避免大面积功能卡片。保留樱夜角色；新背景独立生成，无文字或角色，所有按钮由代码渲染。

真实入口：干员资料、寻访、卡片仓库、采购商店、关卡、档案；另有邮箱、公告、活动（现有三种模式的实际入口）、任务补给、七日签到、设置、整备和近期战绩。邮箱包含一封 200 币欢迎邮件以及已达成里程碑邮件，与任务共用同一领取记录。已读状态独立保存；一键领取只处理可领邮件。七日累计登录奖励 60/80/100/120/140/160/240，每个本机日期最多一次，日期回拨不给奖励，七天完成后不重复循环。公告描述实际开发版本和游戏玩法。

技术：原生 JavaScript；服务数据模块独立于大厅呈现，使用 sakurayoV3 的 shop40.ops.services 保存已读、欢迎领取与最多七个有效日期。旧档迁移保留寻访与既有补给记录。持久化失败时提示保存失败；奖励操作遵守现有本机存档语义。
