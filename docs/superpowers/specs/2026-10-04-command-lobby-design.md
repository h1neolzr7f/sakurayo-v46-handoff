# 樱夜开发版：横屏大厅与出击体验升级

用户目标：保留肉鸽，全面精装修，尤其是大厅，形成可游玩的横版二游体验。

基线：开发仓 main 93edb70；稳定玩家仓独立保留。现有未合并 PR 不盲目整合。继续离线运行、沿用 sakurayoV3、保留全部角色/职业/融合/飞升/主神空间及现有数值。当前源码的寻访装备和收集加成已超出旧交接文档，升级不倒退玩家已有数据。

大厅采用月夜神社指挥室，左侧完整角色、右侧出击操作台，五个现有导航入口保持。新增真实角色资料与装备信息、出击整备、近期战绩、章节里程碑补给。新增补给只奖励已完成的离线里程碑，一次领取，无每日限制。所有状态写入 shop40.ops.supplies，旧档补缺字段，绝不清档。

角色资料读取现有 CHARACTERS35；整备读取当前章节、模式、衣装、初始核心、武器与排除符，提供切换和真实出击。补给以已完成章节/累计局数/击杀数计算，可领取标记与钱包同步。保持原大厅出击直接开始，整备为独立入口。

界面风格：深靛蓝、月白、少量樱粉与金色；减少整屏浓紫玻璃和过强发光。触控按钮至少 40px；低矮横屏适配，窄竖屏保持项目现有兼容。每个入口须连接真实功能，禁止假充值、假社交、空按钮。

美术通过用户指定第三方 gpt-image-2.5 生成无字背景；运行时使用本地 WebP。密钥仅在仓库外临时环境文件，不嵌入游戏、不提交。模型出图失败时明确记录，不假称生成成功。

验收：纯逻辑单元测试（旧档、一次补给、重复领取、锁定里程碑），浏览器走通全部大厅入口、角色切换/衣装/整备/寻访/领取/重载，932×430、844×390、1280×720及430×932布局截图。现有静态与游戏冒烟继续通过；构建单文件 HTML 并同步 Android 离线资源。仍标开发预发布，不宣称正式 APK 验收。

## 追加范围（2026-10-05，用户授权继续）

生成四章独立俯视战场地面、四张章节场景插画和一套八帧指挥印记动画，全部通过指定中转 API 的 gpt-image-2.5 生成并离线 WebP 化。插画用于关卡卡面、整备及章节演出；战场地面保留游戏真实碰撞障碍，不把绘画细节当障碍。四章环境动画有固定数量和可视范围裁剪，低画质降采样，主神保持原有场景。大厅入口与面板加克制的进入/切换反馈，尊重减少动态效果偏好。

关卡改动集中在战术可读性、地面身份和障碍提示；不把画面升级伪装成数值平衡完成。不改原有职业、碰撞规则、Boss 阶段阈值和实体上限。最后集中执行已有52项完整浏览器冒烟、新大厅流程、关卡动画单元和离线打包回归。
