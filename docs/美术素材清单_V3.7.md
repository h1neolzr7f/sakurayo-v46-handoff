# V3.7 美术素材清单

## 规模

- 角色：月城小夜、神代绫、黑羽凛音。
- 非默认服饰：8 套。
- 每组：`portrait.webp`、`dialogue.webp`、`anim_idle.webp`、`anim_move.webp`、`anim_attack.webp`、`anim_hit.webp`、`anim_dash.webp`。
- 合计：24 组、168 个 512×512 透明 WebP，约 9.78 MiB。

## 目录

运行素材位于 `android-app/app/src/main/assets/game/art/characters/<character>/<skin>/`。

Image2 原图位于 `assets/image2/source/`，逐组验收接触表位于 `assets/image2/previews/costumes/`，机器清单位于 `assets/image2/costume_manifest_v37.json`。

## 处理与质量门禁

- `tools/image2/process_costume_sheet.py`：单角色七格表切分、绿幕去底、孤立碎片清理和 WebP 导出。
- `tools/image2/process_costume_atlas.py`：三角色 × 七格图集批处理。
- `tests/check_costume_assets.py`：验证数量、解码、尺寸与非空透明通道。
- 浏览器测试切换三名角色的全部八套服饰，并确认所有商店头像能离线解码。
