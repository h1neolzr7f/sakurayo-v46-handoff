## 2. Boss 三选一
进入层主节点前会弹出选择：割草 / 格斗 / 弹幕射击。路线只给推荐项加金框，三种模式都能选。选择保存在节点的 `mode` 字段上，读档后不会重新弹窗。
平衡口径（自动驾驶，`tests/modes_unit.mjs`、`tests/shmup_unit.mjs`）：
- 格斗：对手胜率按层统计，普通对手 ≥75%；Boss（中等构筑）≥60%，实测约 70%；Boss（满构筑）75–85%，实测约 82%（学习型猜段、起身无敌技、打帧陷阱、识破飞行道具）。
- 弹幕：用“人类水平”自动驾驶（skill 0.3：反应延迟约 0.15 s，判断带噪声），三层 Boss 胜率 ≥75%。
- 割草：沿用原来的层主数值。

## 3. 弹幕射击（`runtime/sakurayo-shmup.js`）
- 低速：Shift、按住「低速」或双指按住。按下后显示判定点（3px，speed 形态 2px）和旋转法阵，移动变慢，子弹收束成集中射击。
- 擦弹：子弹从判定外 22px（speed 形态 28px）内擦过时，加分、加 P、加符卡槽（觉醒）。
- 符卡（Bomb）：消弹，3.2 秒无敌并造成伤害；每个角色的符卡不同。被弹后 0.15 秒内放 Bomb 可以抵消这次被弹（决死）。
- 残机：开局残机 = ceil(带入生命 × 3)，guard 形态 +1，burst 形态 -1。被弹扣 1 残机并掉 P；残机归零则失败。
- Boss：非符和符卡交替。每张符卡都有名字、时限和收取奖励（不被弹、不用 Bomb 打掉）；超时也算突破，但没有奖励。共 13 种几何弹幕，定义见 `pattern()`。
- 三角色：
  - 小夜：高速扩散针弹；低速时为三连收束针。
  - 绫：双枪 + 追踪札；低速时为贯穿细针。
  - 凛音：近身宽幅剑气；低速时为贯穿剑光。
- 美术：`shmup/fly_<角色>.webp`（飞行立绘）和 `shmup/boss_girl_<1-3>.webp`（Boss）。缺图时回退到旧的机体图。

## 4. KOF 式格斗（`runtime/sakurayo-duel.js`）
- 逻辑固定 60fps 帧循环（`frameStep`），所有帧数据在 `MV` 里。
- 指令：236 波动（A），623 升龙（D，起手无敌），214 突进（B，绫为瞬移、凛音为居合当身），236236 超必杀（1 气）。指令窗口见 `CMD`。
- 系统：轻→轻→重目押；普通技可取消成必杀，必杀可取消成超必；防御分上/下/中段；防御中 →+J+K 为防御反击（1 气）；打断对手出招算 Counter（×1.25 伤害、受击硬直更长）；连段有伤害递减（每段 -10%，最低 30%）；有破防值、Hitstop、震屏、火花、受身和拆投；三局两胜，每局 60 秒。
- AI（`ai()`）读取 react 帧之前的对手状态，会防御（读段）、对空升龙、确反、命中后确认连段（取消成必杀/超必）、投和拆投、远距离放波动。Boss 出招前有闪光「!」，并多 6 帧前摇；必杀落空后多 14 帧破绽。
- 美术：`duel/<角色>/<pose>.webp`，共 23 张（22 个关键帧 + idle_m）。制作流程：
  1. 用 gpt-image-2 生成一张侧视 idle 母版。
  2. 其余姿势全部以母版为参考图做编辑生成，保证脸、服装和比例一致（`/workspace/sakurayo-gen/jobs_ftg1.json`）。
  3. 用 rembg（isnet-anime）抠图，所有姿势共用同一个裁切框，着地姿势的脚底对齐地平线（`ftg_post.py`）。
  4. 招式播放用 pose-hold 硬切（KOF 本来就是逐帧硬切），不做混合，所以没有重影。
  5. 只有待机呼吸用 RIFE 补中间帧，并做重影检测：中间帧的半透明像素比例要和关键帧持平（实测 0.049–0.073，关键帧为 0.051–0.072）。走路这类剪影差异大的过渡不做 RIFE。
- 对手是“镜影”：另一名角色的精灵，加暗化滤镜和紫色描边光；Boss 的描边光为红色。

## 5. 樱花弹珠台（`runtime/sakurayo-pachinko.js`）
- 弹珠退出夜行地图，在大厅「樱花弹珠台」按钮进入。玩法：拖动或点按顶部发射口选落点，弹珠穿过钉阵和转风车，落进 7 个奖槽之一。中央大奖槽最窄。
- 每日免费 1 球（存档 `pachi46`），之后每球 80 樱花币。奖品只有樱花币、镜屑和再来一球，不含任何战斗属性。期望收益约 68，低于球价 80（`modes_unit` 断言），不能刷币。
